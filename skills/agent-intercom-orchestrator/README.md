# Agent Intercom Orchestrator Skill

Guidance for creating, routing, supervising, and cleaning up independent Pi, Codex, Claude Code, and OpenCode coworkers through the shared `agent_fleet` tool.

## Installation

The skill is bundled with the Agent Intercom Orchestrator Pi package:

```bash
pi install npm:@dataforxyz/agent-intercom-orchestrator
```

Install the Agent Intercom control plane as well, then restart Pi or run `/reload`:

```bash
pi install npm:@dataforxyz/agent-intercom-pi
```
